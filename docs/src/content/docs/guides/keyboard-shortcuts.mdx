---
title: Keyboard shortcuts
description: Control search without leaving the keyboard.
---

## Search and navigation

<ul class="fl-shortcuts">
  <li><span>Open or close</span><kbd>⌘ Space</kbd></li>
  <li><span>Fallback global shortcut</span><kbd>⌥ Space</kbd></li>
  <li><span>Previous or next result</span><kbd>↑ / ↓</kbd></li>
  <li><span>Open selected result</span><kbd>Return</kbd></li>
  <li><span>Dismiss</span><kbd>Escape</kbd></li>
  <li><span>Copy selected search text, path, URL, or answer</span><kbd>⌘ C</kbd></li>
  <li><span>Open Settings</span><kbd>⌘ ,</kbd></li>
</ul>

## File actions

<ul class="fl-shortcuts">
  <li><span>Reveal in Finder</span><kbd>⌘ R</kbd></li>
  <li><span>Reveal in Finder, alternate</span><kbd>⌘ Return</kbd></li>
  <li><span>Toggle Quick Look</span><kbd>⌘ Y</kbd></li>
  <li><span>Choose indexed folder</span><kbd>⌘ L</kbd></li>
  <li><span>Rebuild the file index</span><kbd>⇧ ⌘ R</kbd></li>
</ul>

## Filters

<ul class="fl-shortcuts">
  <li><span>All results</span><kbd>⌘ 1</kbd></li>
  <li><span>Applications</span><kbd>⌘ 2</kbd></li>
  <li><span>Files</span><kbd>⌘ 3</kbd></li>
  <li><span>Folders</span><kbd>⌘ 4</kbd></li>
  <li><span>First visible dynamic filter</span><kbd>⌘ 5</kbd></li>
</ul>

<kbd>⌘ 5</kbd> selects the first dynamic filter currently shown after
**Folders**.
